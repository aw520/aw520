### [Shopping Cart Application](https://github.com/aw520/shopping-cart-application)

A React application for browsing products and managing cart quantities. Redux Toolkit manages cart state, with live totals and URL based pagination.

**Technologies:** React, Redux Toolkit, Axios, React Router, Vite

### [Video Transcription and Sentiment Analysis](https://github.com/aw520/AI_Driving_Sim_Analysis)

A Python tool for analyzing communication in human and AI driving simulator experiments. It transcribes video, groups speech into five second intervals, and produces sentiment analysis results and visualizations.

**Technologies:** Python, Whisper, NLTK, Pandas, Matplotlib, FFmpeg
